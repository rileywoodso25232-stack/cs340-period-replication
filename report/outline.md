# Final report outline

Write the final report in English and submit PDF. This outline is not a report
of completed work. Number and reference every figure/table and cite sources.

## 1. Introduction and claims

Problem, selected paper, one to three scoped claims, exact original figure/table
references, and the scale of replication.

## 2. Reproduction setup

Starting repository/SHA, modified files, hardware, kernel, OS, compiler/tool
versions, workload acquisition, settings and complete deviation table.

## 3. Results

Paper vs. Ours table on matching metrics/settings, at least three independent
runs, mean and standard deviation, clear figures and links to original logs.

## 4. Analysis of discrepancies

Per-claim verdict, absolute/relative gaps, controlled checks supporting each
explanation, and limitations. Separate observations from hypotheses.

## 5. Extension

Motivated beyond-paper question, one changed factor, fixed controls, observed
results and their implications for the original claim.

## 6. Conclusion

One-sentence verdict: reproduced / partially reproduced / not reproduced.
Lessons about reproducing systems research.

## Contribution statement

Use actual work and Git history from `docs/team.md`, not the planned role list.

## AI usage statement

Disclose material assistance and human verification using `docs/ai-usage.md`.

## References

Start from `references.bib` and add all actually used sources.
