## 主要发现

1. **PERIOD 的 7911/9806 完全复现论文三项指标**，且逐次稳定（标准差 0）。
2. **PERIOD 的 15265**：首次 11、总调度 96 与论文一致；错误调度出现 1 或 3，
   均值 1.22（sd 0.67），论文为 1。另 1 次出现首次 6、错误 2 的早触发且重放不重现，
   按规则记为 `invalid_replay` 并排除。
3. **Serial 的 7911/9806**：首次与总调度与论文一致；错误调度有 ±1 波动
   （7911 一次 7、其余 8；9806 一次 5、其余 4），未完全达到论文“两者完全相同”的表述。
4. **15265 的不可复现早触发不是 Serial 专属**：Period 与 Serial 都曾出现
   “搜索记录早于 11 的失败，但该失败调度重放不触发”的现象；这是本机复现中最需要
   在分析阶段解释的差异。候选 Serial 驱动在 15265 上的记录更不可靠，故不纳入正式对比。
5. 计时只作描述：Serial 在 7911 上更慢，9806 相近；不同机器/负载不可直接比较。
